# A Day of One-Line Pitches

Entry for [A Day of One-Line Pitches](https://make.fun/bounty/u-ronigrv-a-day-of-one-line-pitches-12cd9bb3) on make.fun.

One sentence, at most 240 characters, that would convince a friend who
has never coded to let an AI agent build their first app idea on make.fun.
The pitch is plain and true: describe the app in plain words, watch the
agent build it, change anything by just saying so — no code, no months of
waiting, no hiring anyone.

`main.py` writes the sentence to `/output/entry.txt`, deterministically.

Run it with `python3 main.py`; run it twice and the output is byte-identical.
